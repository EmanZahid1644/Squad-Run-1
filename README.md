# 🚀 SQUAD RUN: The City is Your Lobby

**SQUAD RUN** is a "Cyber-Noir" urban adventure game that transforms your real-world city into a tactical gaming lobby. It uses real-time GPS tracking to turn physical hangouts into high-stakes missions.

---

## 🛠️ Tech Stack
**React Native | Expo | JavaScript | React Navigation | Expo Location | React Native Maps**

---

## 🎯 Features
* **Tactical HUD:** A high-tech gaming interface with neon aesthetics.
* **Live Radar Scan:** Real-time 360° radar animation for squad detection.
* **GPS-Gated Missions:** Proximity-based decryption that only works when you are at the target.
* **Squad Intel:** Live squad status, member distances, and an encrypted chat system.
* **Victory Rewards:** XP and Token reward system upon mission completion.

---

## 🎮 How It Works
1.  **Create a Squad:** Generate a unique mission code and share it with friends.
2.  **Briefing:** Receive your tactical objectives and target coordinates.
3.  **The Hunt:** Use the live map to navigate to the target zone.
4.  **Decrypt:** Stay within the 200m radius and use the "Bypass" button to extract data.
5.  **Claim Rewards:** Secure the area and earn XP for your profile.

---

## 📂 Project Structure
* `App.js`: The navigation hub connecting the Lobby and Map.
* `LobbyScreen.js`: Squad creation and code-sharing interface.
* `MapScreen.js`: The core engine handling GPS, Radar, and Mission logic.

## 🚀 Installation & Setup

1.  **Clone the project:**
    ```bash
    git clone [https://github.com/EmanZahid1644/squad-run.git](https://github.com/yourusername/squad-run.git)
    ```
2.  **Install dependencies:**
    ```bash
    npm install
    ```
3.  **Run with Expo:**
    ```bash
    npx expo start
    ```
4.  **Scan the QR code** using the Expo Go app on your Android or iOS device.
